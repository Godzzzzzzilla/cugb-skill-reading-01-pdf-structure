# pdf-structure

Recover reading order, section hierarchy, table cells, equation numbers and a
character range per block from research PDFs.

This is the submission for **阅读01｜文献文档解析** (product-arena-08).

## What problem it solves

Most PDF text layers store glyphs in producer order. On a two-column paper that
produces the classic failure: the last line of the left column is spliced onto
the first line of the right column, and a model reading the text answers
confidently from a sentence that never existed. The skill replaces producer
order with page geometry:

1. **glyph boxes** from one of four backends (`pdftotext -bbox`, `pdfminer`,
   `pypdf`, raw stream);
2. **reading order** by recursive XY-cut — the widest whitespace strip that no
   glyph crosses, on both axes, so a full-width title forces a horizontal cut
   before the columns below are split;
3. **blocks and paragraphs** — lines merge by vertical proximity and column
   alignment, then split where a line stops short of the column edge and closes
   a sentence;
4. **structure** — headings by font size, numbering and keyword; captions by
   label; equations by trailing `(n)`; tables by recurring column starts;
5. **anchors** — each block is written into `pages/pNNNN.txt` and keeps its
   character range, so the claim and the evidence are the same bytes.

## Install

Nothing to install: Python 3.9+ standard library only. `pypdf` and `pdfminer.six`
are used **if present** and skipped if not; `pdftotext` is used if it is on
`PATH`. `requirements.txt` is empty on purpose.

## Use

```bash
python3 scripts/run.py --input /input/case.json --output /app/output
python3 scripts/verify.py --result /app/output/result.json   # re-slice every anchor
python3 scripts/selftest.py                                  # 17 invariants
python3 bench.py                                             # baseline vs skill
```

`scripts/run.py` never raises: a missing field, an encrypted PDF or a scan
produces a complete `result.json` with `status: partial`/`cannot_determine` and
the reason attached.

## Measured effect

`bench.py` renders a three-page two-column paper from a controlled layout engine,
so the ground truth (block text, block order, table cells, running heads) is
exact rather than annotated. The same bytes are written twice: once with glyphs
in reading order (`paper.pdf`) and once row-major (`paper_interleaved.pdf`), the
order that produces interleaving.

| stream order | metric | baseline (producer order) | this skill |
|---|---|---|---|
| row-major (interleaved) | 40-char window recall | 34.5% | **96.5%** |
| row-major | block-order Kendall tau | 0.897 | **1.000** |
| row-major | running-head lines leaked | 3 | **0** |
| row-major | table cell F1 | 0.00 | **1.00** |
| column-major | 40-char window recall | 96.5% | 96.5% |
| column-major | running-head lines leaked | 3 | **0** |
| column-major | table cell F1 | 0.00 | **1.00** |

The honest reading of that table: when the producer already wrote column-major,
order was never the problem and the skill does not pretend to improve it — what
it adds there is running-head removal and the table matrix. When the producer
wrote row-major, the baseline loses two thirds of its windows and the skill does
not.

`bench.json` is regenerated by `bench.py`; the numbers above are that file.

> `examples/input/paper.pdf` is a synthetic document authored for this
> demonstration. The percentages printed **inside** it belong to its own
> narrative and are not measurements of this skill.

## Failure handling

| input | behaviour |
|---|---|
| encrypted PDF | caught, `status: partial`, exception text in `uncertainty` |
| scanned PDF (no text layer) | `cannot_determine`, OCR named as the fix, no invented text |
| one column narrower than 3% gutter | not split; both columns appear in one block and the audit says so |
| missing case.json | file discovery still runs; empty input degrades to `cannot_determine` |
| unknown case schema | aliases (`id`/`case_id`/`task_id`, `materials`/`files`/`inputs`) are tried before giving up |

## Reuse

`scripts/armkit.py` is a standalone module with no third-party imports; the
layout, anchor and audit parts are reusable for any document task. `demo/paper.py`
regenerates the benchmark and its ground truth byte-for-byte, so the comparison
can be re-run by anyone.

## Limits

- Figures are located by caption, not understood.
- Formula images are reported as missing blocks rather than transcribed.
- Rotated pages are read as upright.
- Column detection needs a whitespace gutter; a rule-drawn gutter defeats it.
